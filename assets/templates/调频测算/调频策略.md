# 调频收益及报价测算 - 策略文档

## 目标

计算调频日内中标时点的**最低申报价格**，用于回答「在覆盖现货损益和容量分摊费用的前提下，最低能以什么价格中标仍然不亏」。

最低申报价格在模板中为「调频测算」sheet 的 B10 单元格，公式为：

```
=-(K7+M7)/C7/D7
```

即：**最低申报价格 = -(现货损益均值 + 容量分摊费用均值) / 综合性能指标均值 / 调节深度均值**

---

### Sheet 1: 调频测算（主表）

| 列 | 列名 | 数据来源 | 说明 |
|----|------|---------|------|
| A | 日期 | 手动填入 | Excel 序列号（如 46167 = 2026-05-25） |
| B | 时点 | =性能记录表格!B | 中标小时，动态行数 |
| C | 综合性能指标(Kp) | =性能记录表格!G | |
| D | 调节容量(MW) | =性能记录表格!H | |
| E | 中标价格(元/MW) | 天机库 | `shandong_px_fm_market_intraday_clearing_price.price` |
| F | 调频收益 | =E×D×C | |
| G | 调频产生用电量 | =调频产生发用电及损益!E | 调频净用电量 |
| H | 用电支出 | =调频产生发用电及损益!F | 调频用电电费 |
| I | 调频产生发电量 | =调频产生发用电及损益!G | 调频净发电量 |
| J | 发电收入 | =调频产生发用电及损益!H | 调频发电电费 |
| K | 调频产生现货损益 | =J+H | 发电收入 + 用电支出（注意是加号，因用电支出为负值） |
| L | 调频综合收益 | =F+K+M | 调频收益 + 现货损益 + 容量分摊 |
| M | 容量分摊费用 | =G×70.5×容量分摊系数!B | 调频用电量 × 70.5 × 时点分摊系数 |

**行结构（动态）：**
- R2-R{n+1}：数据行（根据中标时点数量动态增减）
- R{n+2}：均值行（C=AVERAGE, D=AVERAGE, E=AVERAGE, K=AVERAGE, M=AVERAGE）
- R{n+3}：合计行（F-M=SUM）
- R{n+5}：最低申报价格（B=-(K均值+M均值)/C均值/D均值）

## 自动计算流程

### 输入

- 日期（如 `0525`）
- 月份（如 `5`）

### 步骤

1. **复制模板** — `调频收益及报价测算_20260527.xlsx` 到 `output/调频收益测算/`
2. **写入性能记录表格** — 从本地库 `调频日性能记录` 写入当日数据，动态行数
3. **写入调频测算** — 日期 + 公式引用（B/M/L 列写公式，E 列写中标价），均值/合计/最低申报价格行动态调整位置
4. **写入用电结算单** — 从本地库写入 24 小时数据，含合计行
5. **写入发电结算单** — 从本地库写入 96 刻钟数据
6. **写入实时出清结果** — 从本地库 `润津实时出清结果` 写入 E 列 96 点数据
7. **写入容量分摊系数** — 当月 24 时点系数

### 关键注意事项

- **中标时点每天不同**：行数根据实际中标时点动态生成
- **用电为 24 小时结算，发电为 96 刻钟结算**：模板中的 24 小时汇总通过公式自动完成
- **保留模板公式**：调频测算、实时出清结果、调频产生发用电及损益中的公式不清除，只写数据源单元格
- **调频产生发用电及损益**：全部为公式，无需手动填充
- **最低申报价格在 B10**：公式 =-(K7+M7)/C7/D7

## 本地库数据同步规则（重要）

**原则：所有本地库和天机源表的同类数据，取二者中最新的数据。**

- **天机源表优点**：每日自动更新，数据稳定可靠
- **本地表优点**：可以手动导入天机源表未更新的数据（如从交易中心下载的 Excel 文件）

### 自动同步

`local_db.py` 的 `auto_sync()` 函数已实现全表自动探查。

```bash
python "06 DataMining/local_db.py" auto-sync
```

### 天机库数据更新时间

| 数据类型 | 天机库表 | 更新时间 |
|---------|---------|---------|
| 日前负荷预测 | `shandong_px_spot_dayahead_load_info` | 约 10:15 更新次日 |
| 日前电价（96点） | `shandong_px_reliable_clearing_unit_data` | 约 23:00 更新 |
| 实时电价（96点） | `shandong_px_realtime_clearing_results_query` | 约 23:00 更新 |
| 日内调频出清 | `shandong_px_fm_market_intraday_clearing_price` | 约 23:00 更新 |

### 同步命令

```bash
# 同步全部数据
python "06 DataMining/local_db.py" sync --start YYYY-MM-DD --end YYYY-MM-DD

# 同步指定类型
python "06 DataMining/local_db.py" sync --start YYYY-MM-DD --end YYYY-MM-DD --tables price
python "06 DataMining/local_db.py" sync --start YYYY-MM-DD --end YYYY-MM-DD --tables bidding_space
```

### 相似日分析自动同步流程

每次生成相似日分析 HTML 前，必须执行：

1. **同步竞价空间** — 从天机库 `shandong_px_spot_dayahead_load_info` 取最新负荷预测
2. **同步价格** — 从天机库取 `dayahead_price` + `realtime_price`（96 点电价）
3. **重算特征** — `python similar_day_analysis.py compute`
4. **生成 HTML** — `python similar_day_analysis.py YYYY-MM-DD`
