================================================================================
常用查询示例
================================================================================

1. 查询山东 2026 年 5 月日前出清价格
SELECT date, time_order, price
FROM shandong_px_spot_dayahead_clearing_price
WHERE date >= '2026-05-01' AND date <= '2026-05-31'
ORDER BY date, time_order;

2. 查询山东 2026 年 5 月实时出清价格
SELECT date, time_order, price
FROM shandong_px_spot_realtime_clearing_price
WHERE date >= '2026-05-01' AND date <= '2026-05-31'
ORDER BY date, time_order;

3. 查询山东日前负荷预测
SELECT date, time_order, load
FROM shandong_px_spot_dayahead_load_info
WHERE date >= '2026-05-01' AND date <= '2026-05-31'
ORDER BY date, time_order;

4. 查询山东日前新能源预测
SELECT date, time_order, power
FROM shandong_px_release_constraint_dayahead_new_energy_forecast
WHERE date >= '2026-05-01' AND date <= '2026-05-31'
ORDER BY date, time_order;

5. 查询山东跨省通用表数据（需指定 province_id=14）
SELECT date, time_order, price
FROM all_province_clearing_price_forecast
WHERE province_id = 14 AND date >= '2026-05-01'
ORDER BY date, time_order
LIMIT 1000;

6. 查询算法层出清价格预测
SELECT date, time_order, org_price, fore_price, fore_price_adjusted
FROM algorithm_clearing_price_forecast
WHERE province_id = 14 AND date >= '2026-05-01'
ORDER BY date, time_order
LIMIT 1000;

================================================================================
数据完整性说明
================================================================================
- 大部分表数据覆盖 2026-01-01 ~ 2026-05-29（当前日期）
- 部分表数据截止到 2026-05-24 或 2026-05-27（可能存在数据延迟）
- 跨省通用表（all_province_*）和算法表（algorithm_*）包含多个省份数据，需用 province_id=14 筛选山东数据
- tianji_adjust_ratio_median 系列表使用 time_order 而非 date 字段，需特殊处理
