## 数据结构

### 电价（`报价及预中标` sheet，日前/实时通用）

| 列 | 列号 | 内容 | 行范围 |
|----|------|------|--------|
| G | 7 | 时点序号 (1-96) | 2-97 |
| H | 8 | 时间戳 (`YYYYMMDD HHMM`) | 2-97 |
| **J** | **10** | **统一结算电价（元/MWh）** | 2-97 |
| K | 11 | 节点电价（与 J 相同） | 2-97 |
| N | 14 | 充放电曲线（MW） | 2-97 |

- 96 个时点 = 每日 00:15 ~ 24:00，间隔 15 分钟
- J 列和 K 列数值相同，取 J 列即可

### 竞价空间（`Sheet1`，行 3-6，列 B~CS）

| 行 | 含义 |
|----|------|
| 3 | 直调负荷 |
| 4 | 联络线受电负荷 |
| 5 | 风电总加 |
| 6 | 光伏总加 |

**竞价空间 = 行3 − 行4 − 行5 − 行6**（Excel 源文件 4 项子集公式；标准 5 项定义见 `竞价空间分析工作流程.md`，含核电+自备，地方电厂不参与）

- 列 B(2) ~ CS(97) = 96 个时点（00:15 ~ 24:00）
- 单位：MW

## 提取逻辑（核心代码说明）

### 电价读取

```python
import openpyxl

def read_prices(filepath):
    wb = openpyxl.load_workbook(filepath, data_only=True, read_only=True)
    ws = wb["报价及预中标"]
    times, prices = [], []
    for row in range(2, 98):            # 96 行
        t = ws.cell(row=row, column=8).value   # H 列时间戳
        p = ws.cell(row=row, column=10).value  # J 列电价
        # "20250518 0015" → "00:15"
        time_label = f"{t.strip()[-4:][:2]}:{t.strip()[-4:][2:]}"
        prices.append(round(float(p), 2) if p else None)
        times.append(time_label)
    wb.close()
    return {"times": times, "prices": prices}
```

### 竞价空间读取

```python
def read_bidding_space(filepath):
    wb = openpyxl.load_workbook(filepath, data_only=True, read_only=True)
    ws = wb["Sheet1"]
    values = []
    for col in range(2, 98):  # B(2) ~ CS(97) = 96 点
        r3 = float(ws.cell(row=3, column=col).value or 0)  # 直调负荷
        r4 = float(ws.cell(row=4, column=col).value or 0)  # 联络线受电
        r5 = float(ws.cell(row=5, column=col).value or 0)  # 风电总加
        r6 = float(ws.cell(row=6, column=col).value or 0)  # 光伏总加
        values.append(round(r3 - r4 - r5 - r6, 1))
    wb.close()
    return values
```

> 行 7 的竞价空间是公式（`=B3-B4-B5-B6`），`data_only=True` 读取时缓存值为 None（公式引用同 sheet 其他行，openpyxl 无法解析），因此需从行 3-6 手动计算。

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `UnicodeEncodeError: 'gbk'` | print 含 Unicode 符号 | 避免在 print 中使用 ✓ ✗ ✅ 等符号 |
| 某日缺点（< 96） | 源文件数据不完整 | 正常，缺失值返回 None，图表自动跳过 |
| 找不到文件 | 日期对应文件未生成 | 先完成阶段 01/02/03 的复盘生成 |
| 竞价空间全为 0 | `data_only=True` 读行 7 公式返回 None | 已修复：改为读行 3-6 手动计算 |
