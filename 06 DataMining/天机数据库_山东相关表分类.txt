常用查询示例
================================================================================

1. 查询山东日前出清价格（96点）：
   SELECT date, time_order, org_price, fore_price, fore_price_adjusted
   FROM algorithm_clearing_price_forecast
   WHERE province_id = 14 AND date >= '2026-05-01'
   ORDER BY date, time_order;

2. 查询山东日前/实时统一结算价：
   SELECT date, time_order, price
   FROM shandong_px_spot_dayahead_clearing_price
   WHERE date >= '2026-05-01'
   ORDER BY date, time_order;

   SELECT date, time_order, price
   FROM shandong_px_spot_realtime_clearing_price
   WHERE date >= '2026-05-01'
   ORDER BY date, time_order;

3. 查询山东供需预测（竞价空间基础数据）：
   SELECT datetime, fore_value, fore_type, area_type
   FROM all_province_supply_and_demand_forecast
   WHERE province_id = 14
   ORDER BY datetime DESC
   LIMIT 5000;

4. 查询山东日结算单：
   SELECT *
   FROM shandong_px_statement_spot_daily_v2
   WHERE date >= '2026-05-01'
   ORDER BY date;

5. 查询山东日前新能源预测与实际负荷：
   SELECT a.date, a.time_order, a.dayahead_new_energy_power_forecast,
          b.actual_wind_power, b.actual_photovoltaic_power
   FROM shandong_px_release_constraint_dayahead_new_energy_forecast a
   JOIN shandong_px_spot_actual_load_info b
     ON a.date = b.date AND a.time_order = b.time_order
   WHERE a.date >= '2026-05-01'
   ORDER BY a.date, a.time_order;

6. 查询储能电站日内充放电计划：
   SELECT date, unit_name, time_point, power
   FROM shandong_px_intraday_clearing_plan_result
   WHERE unit_name LIKE '%润津%' AND date >= '2026-05-01'
   ORDER BY date, time_point;

7. 查询每日报价上下限：
   SELECT date, parameter_name, parameter_value
   FROM shandong_px_spot_trade_constraint
   WHERE date >= '2026-05-01'
     AND parameter_name LIKE '%限价%'
   ORDER BY date;
